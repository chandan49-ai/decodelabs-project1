Information Architecture

Structure before code — Dan Brown's Core Principles

📦

Principle of Objects

Treat content as living data rather than static text. Recognize patterns and structure content into reusable UI components.

🎯

Principle of Choices

Minimize cognitive load for users. Keep layouts organized, focused, and free from unnecessary distractions.

⚖️

Separation of Concerns

Maintain clear boundaries. HTML governs structural data, while external CSS manages appearance and layout.

Core Engineering Standards

Designed with Flexbox, CSS Grid, and A11Y Standards

CSS Grid (Macro Structure)

Used for overall two-dimensional page layout grids, card alignments, and main content arrangement.

Flexbox (Micro Alignment)

Utilized for one-dimensional navigation alignment, button groups, and internal component layout control.

DRY & BEM Naming

Don't Repeat Yourself. Modular CSS styling with clean Block-Element-Modifier syntax.

Accessibility (A11Y)

High contrast text ratios (> 4.5:1), descriptive alt attributes for images, and semantic layout tags.
